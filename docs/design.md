# 形象设计说明：提灯的人

## 一句话

一个背对观众的小小背影，一手垂在身侧提着灯。**这盏灯就是她的情绪。**

---

## 为什么用灯表达情绪

短片讲的是"深夜情绪失守"，最难的从来不是把机制讲清楚，
而是让观众**在听懂之前就看见**状态。

灯同时承担三件事：

| 维度 | 表达 | 片中用法 |
|---|---|---|
| 亮度 | 心理能量 | 开场暖金 100% → 深夜压到 12% → 日出回暖 |
| 色温 | 情绪色彩 | 暖黄（正常）→ 冷青（低落/被屏幕盖过） |
| 光照范围 | 世界的样子 | 灯是画面唯一光源，她周围的世界随灯一起明暗 |

所以第 6 段"屏幕越亮，你越暗"里，手机蓝光一压，**她的灯就暗下去，整个场景跟着暗下去** ——
不用一句解释，观众自己会读出来。

---

## 为什么是背影

这是被实现数据推翻三次之后的决定。

**尝试过的方案**

| 方案 | 失败原因 |
|---|---|
| 背影剪影（v1） | 剪影色与夜色几乎同色，人物被背景吃掉 |
| 正面剪影（v2） | 空白脸产生恐怖谷，像人偶不像人 |
| 正面提灯（v3） | 加高光后好转，但 4x 下仍读作"方块人"，缺乏魅力 |

**定稿：背影 + 马尾 + 过膝长裙 + 提灯（v4）**

理由：

1. **零恐怖谷风险** —— 不画脸，就不存在"眼睛画歪了"的问题
2. **情绪带宽更大** —— 背影是天然的"孤独"符号，观众容易代入（Limbo / Journey 同源手法）
3. **视觉焦点明确** —— 灯光打在裙摆下缘与马尾边缘，形成一条发光轮廓线，
   比五官更能建立"这个人有故事"的感觉
4. **可复现** —— 骨架由行号表格定义，纯几何绘制，改一个数字就能调比例，能进 git 做版本对比

## 骨架规格

```
画布 26 × 52 像素，中心 x=13，脚底 y=51
世界显示倍率 4x → 104 × 208 像素（1080p 里约 208px 高）

 0– 4  头顶（圆弧轮廓，内层深色）
 5–14  垂发两绺 / 脸（正面版）/ 后脑（背影版）
 3–29  马尾（随 hair 参数摆动）
10–11  脖子
12–16  肩（最宽 x=7..22）
17–30  上衣 / 腰（逐步收窄）
13–30  双臂下垂（右手在 y=30 提灯）
31–43  裙摆（阶梯式展开，下缘受灯）
44–51  小腿 / 鞋
```

三档亮度（`bright` / `mid` / `dark`）各烘一张 4~5 色位图，
播放时按 `level` 在两张之间交叉混合 —— **避免逐帧改色导致的缩放闪烁。**

---

## 灯的规格

```
灯体   6–8 px 方形灯罩 + 竹骨横线 + 提梁圆弧
灯芯   中心过曝白点 + 三层径向光晕（6r / 3r / 1.6r 半径，强度 0.09 / 0.16 / 0.26）
光束   灯芯下方 26px 细光锥（强度 0.85 × level）
地面   灯下 8–11px 半径的椭圆光池（强度 0.34 × level）
摆动   提灯随 t 正弦轻摆，幅度随灯变暗而增大（暗 = 不稳）
```

灯色随 level 线性插值：
`level=1 → WARM_HOT 过曝暖白` → `level=0.5 → WARM 暖金` → `level=0 → COOL_DEEP 冷青`

## 复用建议

想换角色只动 `nightpix/keeper.py` 的 `_back_pose()` 行号表即可，
`_back_levels()` / `_back_sprite()` / `draw_keeper()` 三层不用改。
想换灯的语义（比如"灯 = 记忆"），改 `draw_keeper()` 里传的 `level` 曲线就行。
