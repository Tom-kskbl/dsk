# Canva 实测记录（第二家生图工具）

> 上一轮用阿里云百炼（通义万相）试过：当精灵不行、当背景板很好。
> 这一轮按要求换 **Canva** 再试一遍，看结论是否一致。

---

## 1. 怎么走通的

Canva 装的是**桌面端**（`C:\Users\Lenovo\AppData\Local\Programs\Canva可画\Canva可画.exe`），
本来只有悬浮球、没有主窗口，直接启动后进了编辑器。

GUI 自动化踩的两个坑（都不是 Canva 的问题，是我的用法）：

| 现象 | 原因 | 解法 |
|---|---|---|
| 点了侧栏没反应 | 窗口没拿到焦点，第一次点击被吃掉 | 先点一下空白处激活，再点目标 |
| 一直点错位置 | 坐标换算错：截图预览 1011px 宽 → 实际屏幕 2560px，倍率是 **2.53** 不是工具标称的 1.48 | 按 2560/1011 重算 |

**Canva AI 入口**：左侧栏 `Canva AI` → 选 `AI素材`（AI Assets）→ 输入提示词 → 提交。
面板还有 `AI生成质量 / 长宽比 / 风格` 三个选项。

**提示词**（中文，Canva 直接吃）：

```
像素画，16位复古游戏风格，深夜的卧室，月光从窗户照进来，深蓝色调，
低亮度，空房间没有人物，安静，无文字
```

生成两张，各 2304×1728。导出为 PNG 时 Canva 桌面端会先写一个 GUID 命名的
`.tmp` 再改名 —— 那个 `.tmp` 其实就是完整 PNG，直接改后缀即可。

产物：`assets/reference/canva/bedroom_night_01.jpg`、`bedroom_night_02.png`

## 2. 结论：和万相一致，但质量更高

| 维度 | 通义万相 | **Canva** |
|---|---|---|
| 单张分辨率 | 1024×1024 | **2304×1728** |
| 像素画纯度 | 好，但偏"渲染感" | **好，块面更干净** |
| 配色 | 偏灰、欠饱和 | **蓝色更饱和、夜色更漂亮** |
| 构图 | 偏空 | **物件更满（床/窗/月亮/床头柜/相框）** |
| 水印 | 无 | **右下角"可画AI生成"** |
| 程序化调用 | ✅ 有 API，可脚本化 | ❌ 只能 GUI 操作 |

**Canva 出的两张明显比我原来用的万相版好看**，已直接接入替换：

- `ceiling_3am`（第 1 段"凌晨的房间"）→ `ceiling_3am_canva.png`
- `sleep_tug`（第 7 段"越想睡越睡不着"）→ `sleep_tug_canva.png`

万相那两张留档在 `assets/reference/backdrops_wanx_*.png` 供对比。

**水印处理**：2304×1728 是 4:3，转 16:9 要裁掉上下 —— 正好把右下角的水印切掉，
不用额外修图。

## 3. 两家工具的共同结论

**精灵 / 人物：两家都不行。** 原因不是工具不好，是**需求不匹配**：

成片素材的硬要求是「像素级精确 + 带 alpha 透明通道 + 帧间完全一致」。
文生图给的是"一张好看的照片"，它没有：

- 透明的背景（抠出来边缘会带残影）
- 逐帧一致的角色（每次生成的姿态、比例都不同，无法动画）
- 受控的像素网格（下采样后关键结构会丢）

所以**人物继续用代码手绘**（`tools/make_pixel_assets.py`），
文生图只负责它真正擅长的：**场景背景板**。

如果要真正把人物提升一个档次，正确的路不是文生图，而是：
1. 手绘/买一套像素角色素材包（spritesheet），或
2. 用文生图出**参考图**，然后由人照着在 Aseprite 里逐像素重画

第 2 条是行业里的常规做法，但那需要人来做，不是我能替代的。

## 4. 关于"用哪家"

| 场景 | 推荐 |
|---|---|
| 要批量、要可复现、要进 CI | 通义万相（有 API，`tools/gen_backdrops.py` 一行命令重出 8 张） |
| 要单张质量最高、愿意手动点几下 | **Canva**（分辨率高、配色好，本次即用此路） |
| 人物素材 | 都不用，走 spritesheet 或人工像素重绘 |
